## 📌 Descrição do Projeto
Este projeto tem como objetivo aplicar e comparar diferentes algoritmos de **classificação** para prever a presença de **doença cardíaca** com base em dados clínicos.

Alguns dos algoritmos utilizados incluem:
- Regressão Logística
- KNN (K-Nearest Neighbors)
- Árvore de Decisão
- Random Forest
- SVM (Support Vector Machine)

O projeto também contempla:
- Análise exploratória de dados
- Tratamento e limpeza dos dados
- Avaliação de desempenho com métricas como acurácia, precisão, recall e f1-score

## 🔧 Etapas Realizadas
- Carregamento e compreensão do dataset.
- Pré-processamento: remoção de valores ausentes e normalização.
- Construção e treinamento de modelos.
- Comparação de desempenho entre os algoritmos.
- Visualização dos resultados com gráficos.

## ▶️ Como Executar o Projeto

1. Clone o repositório:
   ```bash
   git clone https://github.com/JulliaFernandes/Modelos_de_Classificacao_de_Doenca_Cardiaca.git
   ```
2. Acesse a pasta do projeto:
   ```bash
   cd Modelos_de_Classificacao_de_Doenca_Cardiaca
   ```
3. Instale as dependências:
   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn
   ```
4. Execute o arquivo `.ipynb` com o Jupyter Notebook, VSCode ou Google Colab.
